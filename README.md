## FAQ

### Is XCutors free to use?

XCutors is free to download and use. Some bundled executors may have their own premium tiers or key systems — refer to each executor's documentation for details.

### What operating systems are supported?

XCutors is designed exclusively for Windows (10 and 11, 64-bit). macOS, Linux, and mobile platforms are not supported.

### What executors are included in the pack?

The collection currently includes Volt, Synapse Z, Potassium, Wave, and the universal xcutorsLoader for managing them all.

### What is the universal loader (xcutorsLoader)?

xcutorsLoader is a centralized launcher that manages all bundled executors, handles updates, and provides a unified interface so you don't need to run each executor separately.

### How do I update the executors?

The loader checks for updates automatically on startup. You can also manually check by clicking the 'Check for Updates' button in the loader settings.

### Why does my anticomponent flag the executor?

Executor tools often modify game memory, which can trigger false positives from anticomponent software. Add the XCutors folder to your anticomponent exclusion list. Always download from the official GitHub releases page.

### Where can I find scripts to use?

XCutors includes a built-in script hub with curated scripts. You can also browse community forums and script-sharing sites for additional Lua scripts compatible with Roblox.

### Can I suggest a new executor to be added to the pack?

Yes! Open a 'Feature Request' issue on the GitHub repository and provide details about the executor you'd like included. The maintainers review all submissions.

### The executor crashes or won't inject — what should I do?

Make sure Roblox is fully updated, run the loader as Administrator, and ensure your anticomponent is not blocking files. If the issue persists, check the GitHub Issues page for known problems or open a new issue.
